                Proxmox-servers

                Maak in Proxmox een API-token aan: Datacenter, Permissions, API Tokens, Add. Zet "Privilege Separation" uit of geef het token zelf de rol PVEAuditor op pad /. Die rol mag alleen kijken, niets veranderen. Het geheim blijft op je server staan en komt nooit in de browser of in een backup terecht. Voor een cluster is één server genoeg.
